 🤖 Bot clasificador de imágenes con IA

## Descripción
Proyecto que utiliza un modelo de inteligencia artificial entrenado con **Teachable Machine** para clasificar imágenes mediante un bot de Discord.

## Tecnologías y librerías que use
- Python 3.11
- Teachable Machine
- TensorFlow 2.15.0
- Keras 2.15.0
- NumPy
- Pillow
- discord.py
- Requests

## Archivos del proyecto
- `bot.py`: contiene el bot de Discord.
-modelo.py
